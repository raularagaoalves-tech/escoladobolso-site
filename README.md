# Site (repositório público)

Site de vendas da marca, servido pelo GitHub Pages a partir da raiz deste repositório.

- `index.html`: página inicial (provisória, até a marca ter nome).
- `assets/`: imagens, CSS e JavaScript.
- `.nojekyll`: faz o Pages servir os arquivos como estão.

Este repositório é público: não coloque aqui os arquivos dos produtos pagos. O botão de compra de cada produto aponta para o checkout externo, que cobra e entrega o arquivo.

## Publicar

1. Enviar este repositório para a organização da marca no GitHub.
2. Em Settings > Pages, escolher a branch `main` e a pasta `/ (root)`.
3. Depois de registrar o domínio, informá-lo em Settings > Pages > Custom domain.
